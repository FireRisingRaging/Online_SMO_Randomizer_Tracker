Controls
Drag a node
Hold left mouse and drag from one node to another to draw a connection arrow. A node can carry any number of arrows, except dead-end nodes.
Left-click a node
Highlights every chain running through it, and opens the connection navigator below the header. Click again (or empty canvas) to clear.
Right-click a node
Cycles its color through the palette, then back to none. With Segmented Nodes on, colors the entrance, name, or exit separately.
Double-click a node
Removes all of its outgoing arrows at once.
Double-click an arrow
Removes just that connection and splits its chain (the part after the break becomes a new chain).
Ctrl + click a node
Opens its loading-zone screenshot (Stage Previews must be on).
Click an arrow
Highlights that path on the map and the Display panel; click again to clear. Also opens its chain picker so you can link it to another chain or start a new one.
Hover an arrow
Shows which letter chain it belongs to.
Connection navigator
With a node selected, the bar under the header steps through each chain through it. Use its arrows or the Left / Right arrow keys.
Notes
Double-click empty canvas to add a sticky note; shift-click a note to delete it. The Notes panel (Settings) keeps a numbered list. {icon} tokens render as images in both.
Undo / redo
Ctrl + Z undo and Ctrl + Shift + Z redo connections, chain changes, colors, notes, and node moves.
Panels
Drag a kingdom's background or header to move it; drag its bottom-right triangle to resize. Drag a panel's bar to resize the Display and Notes panels.
Decouple
Drag a node's bottom-right triangle to move it on its own. Dragging anywhere else still draws an arrow.
Navigate
Scroll to zoom, drag empty space to pan.

Info
Striped loading zones
These represent one-ways: one entrance in or out.
Segmented Nodes
The arrow attaches to whichever part you start on and release on (entrance, name, or exit). Only the segment under the cursor lights up as in indicator.

Settings

Grid Layout
Set how many columns to arrange kingdom panels in. Rows are calculated automatically. Resets any manual panel positions and sizes.

Stage Previews
Ctrl + Click on PC and hold on mobile, on any kingdom or zone node to view its loading zone screenshot.
Painting Tracker
Adds a Paintings section. Paintings only connect to other paintings, shows at the top of the Display.
Moon Tracking
Adds moon icons per node. Ctrl + Click (PC) or hold (mobile) a node to pick its moon icons; chosen icons show as tiny icons above the node. Works with Stage Previews on (moon buttons appear in the preview popup) or off (opens a moon-only picker).
Segmented Nodes
Splits every zone node into an entrance segment on the left and an exit segment on the right.
Segment labels
Decouple
Frees every node from its kingdom panel so it can be placed anywhere on the map. Each node gets a small triangle in its bottom-right corner: drag that to move the node; dragging anywhere else still draws an arrow. The triangle does not resize nodes.
Note: node positions are saved while Decouple is on, but turning it off does not keep them. The map returns to grouped panels at 4 columns (all arrows are kept).
Arrow Color
Choose how connection arrows are colored on the map.

Node Colors
Right-click a node to cycle it through these colors, then back to none. Add or remove colors below; click a swatch to change it.
Fill tints the node; Frame draws a second border. Turn on both to get both, using the same color. With Segmented Nodes on, each part colors on its own.
Chain Highlighting
Hover or click an arrow on the map (or a path in the Display panel) to highlight it on both.
Display Panel Position
Choose where the chain display panel appears relative to the map canvas.
Notes Panel
A docked panel of numbered notes. Click to add a note and type; {icon} tokens work like the sticky notes. Shift-click a note to delete it.
